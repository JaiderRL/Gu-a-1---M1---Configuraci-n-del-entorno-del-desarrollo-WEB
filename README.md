# MiPrimerProyectoWeb

Primer proyecto web con HTML5: **TecnoVida – La inteligencia artificial en la vida diaria**.

## Estructura

```
MiPrimerProyectoWeb/
├── index.html
├── css/styles.css
├── js/main.js
└── img/ia-ilustracion.svg
Documentacion/
├── documentacion.pdf
└── capturas/
```

## Cómo ejecutarlo

1. Abrir la carpeta en Visual Studio Code.
2. Clic derecho sobre `MiPrimerProyectoWeb/index.html` → **Open with Live Server**.
3. La página se abre en `http://127.0.0.1:5500`.
